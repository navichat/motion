🔍 FaceFormer Model Output Comparison

📋 Overview

This tool compares the outputs of the Python FaceFormer model with the JavaScript/ONNX implementation to ensure consistency.

Process:

  1. Run Python model with test data and save outputs
  2. Run JavaScript model with same test data
  3. Compare outputs (shapes, values, statistics)
  4. Generate detailed comparison report
