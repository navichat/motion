# Avatar AI quick reference

This page lists a few high-frequency commands, URLs, and knobs for exercising the Ichika conversation and classroom demos with on-device backends.

## Local server

- Start the dev server (with COOP/COEP headers enabled):
	- npm script starts it automatically for tests; to run manually:
		- PORT=8080 python3 dev/web_viewer/serve_with_headers.py

## Conversation demo (mic + reply)

- URL: /dev/web_viewer/demos/ichika_voice_conversation_demo.html
- Query hints:
	- backend=speech|kokoro|speecht5|beeps
	- asr=fake|whisper|browser (fake recommended for CI)
	- speecht5OnDevice=1 to enable transformers.js synthesis
	- speecht5OnDeviceFake=1 to force a deterministic local path (no model downloads) for CI
	- kokoroJs=/vendor/kokoro.min.js or kokoro=<model-id or .js URL>
	- runtime.ort=/vendor/ort-wasm.min.js (enables ORT-backed features)
- Notes:
	- Auto-selects Kokoro if a kokoro runtime/model hint is present.
	- SpeechT5 path uses stub/ORT tasks in this demo (no on-device pipeline here).
	- Fake ASR provides a deterministic transcript while still exercising mic permission and reply/animation.

## Classroom conversation backends (VRM E2E harness)

- URL: /dev/web_viewer/tests/e2e/html/classroom-conversation-backends.html
- Query:
	- backend=speech|kokoro|speecht5
	- text=hello classroom
	- kokoroJs=/vendor/kokoro.min.js or kokoro=<model-id or .js URL>
	- runtime.ort=/vendor/ort-wasm.min.js
- Behavior:
	- Schedules visemes/energy and reports expressions via window.__classroomConv.
	- Kokoro uses window.kokoro or KokoroTTS.from_pretrained(); energy computed from audio when available.

## On-device SpeechT5 in classroom demo

- The classroom demo now provides speaker embeddings by default to avoid runtime errors.
- Override with query:
	- speecht5Spk=zero → 512-d zero vector
	- speecht5Spk=random → small deterministic random vector
	- speecht5Spk=<URL-or-path> → let transformers.js fetch/resolve the speaker embedding

## Playwright quick runs (with shell timeouts)

- Run the classroom conversation E2E smoke:
	- npm run test:e2e:classroom:conversation:local
- Run the demo conversation backends unit-web:
	- npm run test:demo:conversation:backends:local
- Run a broader root e2e smoke bundle:
	- npm run test:e2e:root-smokes:local

- Run the ultimate mic→reply E2E only (fake ASR):
	- npm run test:e2e:ultimate:local
- Run root smokes then ultimate E2E together:
	- npm run test:e2e:root+ultimate:local

## Troubleshooting

- If AudioContext stays suspended, click the page once to resume audio.
- For Kokoro model loading via transformers.js: use kokoro=<model-id> (e.g., onnx-community/Kokoro-82M-v1.0-ONNX) or kokoroJs=<.js runtime>.
- For ORT-backed tests, ensure runtime.ort is set or source dev/web_viewer/.env generated by setup.
