🚀 Quick Start

Get up and running in 2 minutes with these simple commands:

# Clone and install git clone https://github.com/navichat/motion.git cd motion && npm install # Start development server npm run dev # Quick shortcuts npm run demo:voice # Voice conversation demo npm run demo:classroom # VRM classroom system

Recommended: Start with the Voice Conversation Demo - it's the most stable and shows the working Ichika avatar that you can talk to!
